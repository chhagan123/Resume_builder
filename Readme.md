# 🤖 AI-Powered Resume Builder

An intelligent web application that helps users **create professional, personalized resumes** using **AI-generated content**.  
Simply input your skills, experience, and goals — and let the AI craft a compelling resume for you in seconds!

---

## 🚀 Features

- 🧠 **AI Resume Generation:** Automatically generates well-written, ATS-friendly resumes using OpenAI or Gemini APIs.  
- 🎨 **Custom Templates:** Choose from multiple modern, clean, and responsive resume templates.  
- ✍️ **Smart Suggestions:** AI suggests better phrasing for skills, job descriptions, and achievements.  
- 📤 **Download & Share:** Export your resume as PDF or share via a link.  
- 🔒 **Secure & Private:** Your data stays safe — no third-party sharing.  
- 🌐 **Responsive UI:** Built with React and Tailwind CSS for a smooth experience across all devices.
